# Pocket Pals Collective

je veux developper ce projet en html css javascript tailwind avec de vrais icones avec le meme design mais si tu peux ameliorer l'experience utilisateur pour que ca soit plus facile a utiliser. et une architecture excellente et en pwa

Choix confirmés :

Stack : React + Tailwind en PWA (pas de HTML/JS pur).

Paiements : simulation pour commencer, sans encaissement réel.
Projet : « Max it Partage », une app de collectes d'argent entre amis avec les 8 écrans de la maquette. Design : j'envoie les captures de maxit_Partage.png pour reproduire le design.
Construis la première version de Max it Partage en reproduisant les 8 écrans de la maquette, avec Lucide, Tailwind et une PWA. c'est un hackaton organiser par orange
